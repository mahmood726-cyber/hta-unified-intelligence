## Abstract
**Background:** HTA recommendations usually combine many evidence dimensions informally: bias, information size, temporal stability, transportability, value, and methodological sensitivity. Fragmented appraisal can yield contradictory narratives even when all the underlying metrics are available.

**Methods:** The Unified Intelligence System integrates multiple upstream engines into a weighted Unified Decision Score and augments that score with Triple-Guard Ensemble Pooling as a robustness guard rail. The codebase combines R and Python components with a dashboard generator for reviewer-facing output.

**Results:** Local materials include the integrated manuscript draft, configuration files, scripts for the master pipeline, dashboard generation utilities, and output assets linking evidence-integrity, transportability, value, and guard-rail metrics.

**Conclusions:** UIS is presented as a self-correcting HTA integration layer whose value lies in making disagreement visible and traceable, not in collapsing complex evidence to a single unquestionable score.

## Introduction
The system is designed for situations where a reviewer needs to see how multiple evidence-quality engines interact, which defaults were used when data were missing, and whether an apparently favorable technology remains favorable when alternative meta-analytic guards are applied.

The relevant comparison is the standard siloed HTA workflow rather than a single competing package. UIS adds integration, configuration transparency, and a dashboard layer over existing evidence engines.

The manuscript structure below is deliberately aligned to common open-software review requests: the rationale is stated explicitly, at least one runnable example path is named, local validation artifacts are listed, and conclusions are bounded to the functions and outputs documented in the repository.

### Limitations
- Some pillars may still rely on conservative defaults when upstream data are incomplete.
- Weight choices and threshold choices remain design decisions that should be reported transparently.
- The integrated verdict is only as strong as the availability and validity of its component engines.
